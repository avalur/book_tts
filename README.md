# book_tts

Персональный сервис для создания аудиокниг на русском и английском языках.
Приоритеты — понятное произношение, спокойное чтение, сохранение содержания и удобная навигация по главам.

## Статус

Проект находится на этапе планирования. Реализация ещё не начата.

Подробности: [план проекта](PLAN.md).

## Планируемые возможности

- Импорт EPUB, FB2 и TXT.
- Выбор голоса и пробное прослушивание перед обработкой книги.
- Локальный запуск с возможностью использовать облачный GPU.
- Продолжение после сбоя и перегенерация отдельных фрагментов.
- Экспорт M4B с главами и MP3 по главам.

Первый этап — сравнить голоса и измерить скорость синтеза на реальных отрывках книг.
